# Tanisha Purohit: Portfolio
```
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```
- Edit `src/data.js` to change text, contact details and project links (add `linkedin` / `github` and each project's `github` / `demo` URLs; empty ones stay hidden).
- Resume lives at `public/resume.pdf`. Replace the file to update it.
- Theme colours are in `tailwind.config.js` (`pink`, `gold`, `ink`).
- The "Send a message" form opens the visitor's email app addressed to you. To receive messages without that step, connect a form service such as Formspree.
